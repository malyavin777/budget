# Бюджет API — установка

Серверная часть на Google Apps Script. Она записывает операции в ваши таблицы, создаёт файл нового месяца и считает отчёт с прогнозом. Работает в вашем аккаунте Google бесплатно.

Установка состоит из двух частей. Сначала Claude Code на вашем компьютере переносит код из этого репозитория в Apps Script (Часть А). Потом вы один раз запускаете несколько функций в редакторе (Часть Б).

---

## Часть А. Перенос кода — делает Claude Code

**Перед стартом, вручную, 1 минута:** откройте https://script.google.com/home/usersettings и включите **Google Apps Script API**. Без этого переключателя код не загрузится.

Затем вставьте в Claude Code:

```
Перенеси бэкенд из репозитория malyavin777/budget в Google Apps Script:
1. Если репозитория ещё нет на компьютере — склонируй его в постоянную папку
   (например ~/Projects/budget), иначе сделай git pull.
2. В папке apps-script войди в Google:  npx -y @google/clasp@2.4.2 login
   (откроется браузер — я подтвержу вход аккаунтом malyavin777@gmail.com).
3. Если в apps-script ещё нет .clasp.json — создай проект:
   npx -y @google/clasp@2.4.2 create --type standalone --title "Бюджет API" --rootDir .
   Если create перезаписал appsscript.json — верни нашу версию: git checkout -- appsscript.json
4. Загрузи код:  npx -y @google/clasp@2.4.2 push -f
5. Открой проект в браузере:  npx -y @google/clasp@2.4.2 open
.clasp.json в git не добавляй (он в .gitignore). Если clasp 2.4.2 не работает —
возьми актуальную версию @google/clasp и подбери соответствующие команды.
```

## Часть Б. Первый запуск — в редакторе, 10 минут

Запуск функции: выберите её в списке над кодом и нажмите **▶ Выполнить**. Результат появится внизу, в «Журнале выполнения».

**1. Резервная копия.** В Google Диске нажмите правой кнопкой на папку «Бюджет» → **Скачать**.

**2. `setup`.** Google спросит разрешения → выберите свой аккаунт. Появится «Приложение не проверено» — это нормально для личного скрипта: **Дополнительные настройки → Перейти на страницу «Бюджет API» → Разрешить**. Скрипт просит доступ к Диску и Таблицам (бюджет), к триггерам (ночная задача) и к отправке писем вам (об ошибках). Читать почту он не может.

В журнале появятся:
- ссылка на папку «Бюджет» (скрипт нашёл её сам);
- ссылка на новую таблицу «Бюджет — Служебное»;
- **код доступа** — сохраните его в заметки, он нужен обоим телефонам.

**3. `migrateHistory`.** Переносит итоги 21 месяца, занимает 1–3 минуты. В журнале будет список статей без группы. Откройте «Бюджет — Служебное» → **Справочник_категорий** и впишите группу в строках «нужно указать»: Еда, Дом и жильё, Транспорт, Дети, Здоровье и забота, Одежда, Работа и учёба, Досуг, Личное, или свою. Группа связывает старые и новые названия статей для прогноза.

**4. `testReadOnly`.** В журнале: «Октябрь 26», около 40 статей расхода и 9 дохода, план 203 900.

**5. `testAddAndUndo`.** Записывает доход 1 ₽ и сразу отменяет. В журнале три ответа: `ok`, `duplicate: true`, `undone: true`. В листе «Октябрь» строки с 1 ₽ остаться не должно.

## Часть В. Публикация — снова Claude Code

```
В папке apps-script репозитория budget опубликуй веб-приложение:
npx -y @google/clasp@2.4.2 deploy -d "v1"
Затем покажи адрес: https://script.google.com/macros/s/<ID развертывания>/exec
(ID — из вывода deploy или из clasp deployments; не @HEAD).
```

Сохраните адрес рядом с кодом доступа. Проверить его можно так (подставьте свои значения):

```bash
curl -sL -H 'Content-Type: text/plain' -d '{"token":"КОД","action":"report"}' 'АДРЕС'
```

Ответ начинается с `{"ok":true,"ym":"2026-10"…`.

Без кода доступа адрес ничего не отдаёт и не записывает, а попытки пишет в лист «Журнал».

## Обновление кода

```
В репозитории budget: git pull, затем в apps-script
npx -y @google/clasp@2.4.2 push -f
и обнови существующее развертывание, чтобы адрес не сменился:
npx -y @google/clasp@2.4.2 deploy -i <ID развертывания> -d "<описание>"
```

## Что работает само

| Когда | Что делает |
|---|---|
| Каждую ночь ~00:10 | Если файла текущего месяца нет — копирует прошлый в папку года («Ноябрь 26»), переименовывает лист операций, очищает операции, план оставляет черновиком, даёт доступ тем же людям |
| С 1-го по 10-е | Обновляет итоги прошлого месяца в «Истории» |
| Запись в первые минуты месяца | Файл создаётся прямо при записи, если ночная задача ещё не прошла |
| Ошибка | Строка в листе «Журнал» и письмо вам |

## Обслуживание

- **Сменить код доступа:** `rotateToken`, затем ввести новый код на обоих телефонах. **Забыли код:** `showToken`.
- **Новая статья:** добавьте её в «Сводку» как обычно, приложение увидит её в течение 10 минут. Группу для прогноза впишите в «Справочник_категорий»; `listUnmappedCategories` покажет, у каких статей её нет.
- **Проверка на копии папки:** ⚙️ Настройки проекта → Свойства скрипта → `ROOT_FOLDER_ID` = ID копии.

## Таблицу стоит поправить заранее

1. «Сводка», K26: `=SUM(K27:K48)` вместо `=sum(K27:K57)`, иначе блок «Инвестиции» попадёт в доход.
2. «Захаренко 7», F60: вернуть формулу `=if(isblank($B60); ""; D60-E60)`.

Новый месяц — это копия прошлого, поэтому достаточно поправить один раз, и правка перейдёт во все следующие месяцы.
